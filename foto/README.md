# Folder foto

Taruh foto di folder ini dengan nama file **persis** seperti di bawah — begitu file-nya ada, foto langsung muncul di situs tanpa perlu edit HTML sama sekali.

| Nama file | Muncul di | Rasio ideal | Isi yang disarankan |
|---|---|---|---|
| `hero-1.jpg` | Polaroid besar di hero | 4:5 (potret) | Kamu lagi kerja / di balik layar |
| `hero-2.jpg` | Polaroid kedua di hero | 4:5 (potret) | Candid / on-camera |
| `tiktok-1.jpg` | Content corner #1 | 9:16 (vertikal) | Screenshot konten KlipKlip terbaik |
| `tiktok-2.jpg` | Content corner #2 | 9:16 (vertikal) | Build in public / BTS |
| `tiktok-3.jpg` | Content corner #3 | 9:16 (vertikal) | Crafting / upcycling |
| `about.jpg` | Section About | 4:5 (potret) | Foto santai yang paling "kamu banget" |

Tips:
- Format `.jpg` (kalau file-mu `.png`/`.heic`, convert dulu atau minta Claude yang convert).
- Usahakan ukuran file di bawah ~500 KB per foto biar situs tetap ngebut (bisa di-resize ke lebar ±1000px).
- Rasio nggak harus persis — foto otomatis di-crop rapi (`object-fit: cover`).
